# Notes / Important Information

## 🔤 Encoding

MirrorShard 2 strongly recommends using **UTF-8 (without BOM)**.

Supported encodings:

* UTF-8
* Shift-JIS

Other encodings (such as EUC-JP or ISO-based formats) may not be handled correctly.

### ⚠️ Important

If a file appears garbled, **do not save it**, as this may overwrite the original data.

Please close the file without saving and convert it to UTF-8 using another editor if necessary.

---

## ⚠️ Limitations

* Encoding detection is not perfect
* In rare cases, garbled text may occur without warning
