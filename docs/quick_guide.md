# **MirrorShard 2 – Quick Guide**

MirrorShard is a writing editor that combines an **idea processor** and **AI tools**, allowing you to go from ideas to structured text in one place.

---

## ■ Installation

**Windows:**
Double-click `MirrorShard 2_1.7.0_x64_ja-JP.msi` and follow the installer.

**Mac:**
Open `MirrorShard.2_1.7.0_aarch64.dmg` and drag the app into the Applications folder.

Linux：
Use the provided binary packages (`MirrorShard 2_1.7.0_amd64.deb` `MirrorShard 2-1.7.0-1.x86_64.rpm` or `MirrorShard 2_1.7.0_arm64.deb`) or build from the source code.

---

## ■ Before You Start (AI Setup)

To use AI features, you need an **API key**.

We recommend starting with **Google Gemini** (free with a Google account).

### Setup Steps

1. Go to:
   [https://aistudio.google.com/](https://aistudio.google.com/)

2. Log in with your Google account

3. Click **"Get API Key"**

4. Select **"Create API key in new project"**

5. Copy the API key

6. Press **F2** in MirrorShard (opens Settings)

7. Open **AI Settings** tab

8. Paste the API key into **"Gemini API Key"**

---

## ■ Idea Processor (Basic Usage)

The Idea Processor lets you freely place and connect ideas on a canvas.
It works like a flexible mind map.

---

### Quick Start

1. Press **Ctrl + I** to open the Idea Processor

2. Make sure AI selector is set to **"Gemini (Cloud)"**

3. Double-click anywhere to create a node

4. Enter some text

5. Click the node to select it

6. Press **Ctrl + Shift + F** (Activate AI)

→ AI will generate related ideas

---

### Basic Controls

* Create node: Double-click
* Edit node: Double-click
* Connect nodes:
  Hold **Ctrl** and click another node

## ■ Useful Shortcuts

* **F1**: Help (shortcut list)
* **F2**: Settings
* **Ctrl + Shift + A**: AI Chat
* **Ctrl + I**: Idea Processor

## ■ FAQ

**Q. Where are settings?**
A. Press **F2** or click the gear icon.

---

**Q. AI is not working**
A. Make sure you have set an API key in Settings.

---

**Q. Can I chat with AI?**
A. Yes. Press **Ctrl + Shift + A**.

---

**Q. What are .md files?**
A. They are text files (Markdown format).
You can open them with any text editor.
