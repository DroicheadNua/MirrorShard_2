# MirrorShard 2 クイックガイド  

MirrorShardは、アイデアプロセッサとAI機能を備え、アイデアを形にできるテキストエディタです。

アイデア整理から執筆までを一つの環境で行うことができます。

────────────────────
■ インストール
────────────────────

Windows：
「MirrorShard.2_x64_ja-JP.msi」をダブルクリックしてインストールしてください。

Mac：
「MirrorShard.2_aarch64.dmg」を開き、アプリケーションフォルダへドラッグしてください。

────────────────────
■ 使用前の準備
────────────────────

本エディタのAI機能を使うには、APIキー（AIを利用するための認証キー）の取得が必要です。
まずはGoogle GeminiのAPIキーを取得してみましょう。
（※Googleアカウントがあれば無料で利用できます）

【手順】
1. GoogleアカウントでGoogle AI Studio  
https://aistudio.google.com/  
にログイン
2. 画面左下の「Get API Key」をクリック
3. 「Create API key in new project」でAPIキーを生成し、その文字列をコピー  
　※APIキーは他人に知られないよう、厳重にご注意ください  
4. MirrorShardでF2キーを押す（設定ウィンドウが開きます）
5. 「AI設定」タブを選択して「Gemini API Key」欄にコピーしたAPIキーを貼り付け

────────────────────
■ まずは動かしてみましょう
────────────────────

APIキーを入手したら、以下の手順で実際にAI機能を試すことができます。

1. アイデアプロセッサを起動する：タイトルバーのアイデアプロセッサボタン（またはCtrl+I）を押す  
2. AIセレクタが「Gemini (Cloud)」になっていることを確認（違う場合は選択してください）  
※AIセレクタは画面右上付近にあるプルダウンメニューです
3. ノード（メモ）を作る：画面をダブルクリックして好きな内容を書き込む  
4. ノードを選択する：作成したノードをクリック  
5. ボタン群の一番左下にあるActivate AIボタン（または Ctrl + Shift + F）を押す

→ 新しいアイデアが自動的に生成されます

────────────────────
■ アイデアプロセッサの使い方
────────────────────

アイデアプロセッサ（※デモ動画で使用していた機能）は、思いつくままに画面にアイデアを書き付け、それを線でつないだりして思考を展開するツールです。マインドマップに似ていますが、より自由な操作が可能です。

【基本的な使い方】
1. 起動する：タイトルバーのアイデアプロセッサボタンまたは（Ctrl+I）を押す
2. ノード（メモ）を作る：画面をダブルクリックして好きな内容を書き込む
3. ノードとノードをつなぐ：ノードを選択したあと、Ctrlキーを押しながら他のノードをクリックする
4. ノードを編集する：ノードをダブルクリックする
5. AIにアイデアを考えてもらう：ノードを選択してAIボタン（またはCtrl+Shift＋F）を押す

👉その他、詳細は同梱の「docs」フォルダ内のガイドをご覧ください。

────────────────────
■ よくある質問
────────────────────

Q. 設定画面はどこですか？  
A. タイトルバーの歯車アイコン、または F2キーで開けます。

Q. エディタの使い方がよく分かりません  
A. F1キーでヘルプ（ショートカット一覧）を表示できます。

Q. AIとチャットできますか？  
A. 可能です。Ctrl + Shift + A キーでチャット画面を開けます。

Q. 他にどんな機能がありますか？  
A. 詳細は付属のドキュメント（features.md）をご覧ください。

Q. .mdファイルとは何ですか？  
A. Markdown形式のテキストファイルです。
　通常のテキストファイルと同様に編集できます。
